Jafar is a fast JFR parser for the JVM with a small API. It includes jfr-shell, an interactive shell for JFR recordings and heap dumps. Ask a question in plain words. The shell writes JfrPath queries, runs them, and shows each query and its result.

05 // Install

Shell, library or Go module.

The parser is a multi-release JAR. It runs on Java 8 and uses faster code on Java 21 and later. The shell and the MCP server need Java 26 or later. Jafar is in early public release, so the API can change.
